An interactive, responsive single-page web application designed specifically for **Class 8 students under the West Bengal Board of Secondary Education (WBBSE)**. Built with high-fidelity 3D flashcards, zero-latency synthesized web audio, HTML5 Drag-and-Drop exercises, and Bengali-to-English grammar breakdowns.

🌐 **Live Application:** [https://atribhowmik248-a11y.github.io/wbbse-class8-english-master/](https://atribhowmik248-a11y.github.io/wbbse-class8-english-master/)

---

## 🎯 Key Learning Modules

### 1. 📖 Textbook Lessons (Blossoms Class 8)
- **Lesson 10: Tales of Childhood by Roald Dahl**
  - 25 Interactive Flashcards with MCQ tests & flipped analytical solutions.
  - 10 HTML5 Drag-and-Drop passage completion exercises.
  - Complete coverage: Llandaff Cathedral School, Mrs. Pratchett's sweet shop, the Great Mouse Plot, Thwaites' father's advice, cane punishment, Norway summer holidays.
- **Lesson 11: Midnight Express by Alfred Noyes**
  - 20 Interactive Flashcards covering Mortimer's childhood encounter, the terrifying 50-year-later repetition, the solitary railway station, the man in the cottage, and the mysterious battered yellow book.
  - 10 HTML5 Drag-and-Drop cloze tests with touch support.
- **Bonus Reference: The Great Escape**
  - Netaji Subhas Chandra Bose & Sisir Kumar Bose's historical escape from Elgin Road residence (Wanderer car, disguise as Mohammad Ziauddin).

### 2. 📝 Comprehensive Class 8 English Grammar Syllabus (105+ Questions)
- **Clauses:** Noun Clauses, Adjective / Relative Clauses, Adverbial Clauses (Time, Place, Reason, Condition, Purpose, Result, Concession).
- **Modals:** Expressing Ability (*can/could*), Permission (*may/can*), Possibility (*might/may*), Obligation/Advice (*must/should/ought to*), Semi-modals (*need, dare, used to*).
- **Infinitives & Gerundials:** Simple Infinitives, Gerundial Infinitives, Bare Infinitives (after *make, let, bid, see, hear*), and *too...to* transformations.
- **Prefixes & Suffixes:** Negative prefixes (*un-, dis-, im-, in-, ir-, il-, non-*), Noun suffixes (*-tion, -ment, -ness, -hood*), Adjective suffixes (*-ful, -less, -ous, -able*), Adverb suffixes (*-ly*).
- **Voice Change:** Active & Passive across all tenses, Modals, Imperative orders/requests, Interrogative sentences, and Quasi-passive verbs.
- **Narration Change:** Direct to Indirect speech across Assertive, Interrogative (*wh-* and *if/whether*), Imperative (*ordered/advised/requested*), Optative, Exclamatory, and Universal truths.
- **Articles & Prepositions:** Vowel sound exceptions (*a university, an honest man*), Definite articles, and Fixed/Appropriate prepositions.

## 🎮 Interactive Features & UX

- 🎴 **3D Flip Flashcards:** Interactive cards with realistic 3D perspective, smooth flipping, Bengali context, and detailed grammatical explanations on the reverse side.
- 🧩 **HTML5 Drag-and-Drop:** Intuitive word tile placement into sentence blanks with 4 word options per question, visual target indicators, and full touch/tap fallback for mobile & tablet users.
- 🔊 **Zero-Latency Web Audio API Synthesizer:** Fully procedural sound effects without external audio file dependencies (Chime, Error Buzzer, Flip Swoosh, Streak Multiplier, Fanfare).
- 🗣️ **Text-to-Speech (TTS):** Native Web Speech API integration to read sentences and words aloud in authentic English accent.
- 🌓 **Modern Dark / Light Mode:** High-contrast color palette, glassmorphism design, responsive layouts, and saved preferences via `localStorage`.
- 📊 **Gamification & Progress Tracking:** Real-time accuracy metrics, streak counters with visual fire badges, celebration confetti animations, and module score cards.

## 🚀 How to Run Locally

No build tools, npm packages, or web server setups are required:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/atribhowmik248-a11y/wbbse-class8-english-master.git
   ```
2. Open `index.html` directly in any web browser (Chrome, Firefox, Edge, Safari):
   ```bash
   # On Windows
   start index.html
   ```
